# Pacheco

## Estructura

- `App/Api`: servidor Node.js, API y datos de vehículos
- `App/Client/page/index.html`: página principal
- `App/Client/Styles/index.css`: estilos
- `App/Client/Scripts/index.js`: interacciones del frontend

## Ejecución local

Desde la raíz del proyecto:

```bash
cd App/Api
npm start
```

Abre `http://localhost:3000/`. El servidor entrega la página desde `App/Client/page/index.html` y sirve los estilos y scripts desde `App/Client`.
